本地浏览器扩展

钉钉直播回放下载器

解压后安装到 Chrome 或 Edge，用当前浏览器已经登录的钉钉账号下载已授权回放。

请只下载你有权访问、保存和学习分析的回放。本工具不会绕过钉钉登录、访问权限或 DRM。

安装步骤

  1. 打开浏览器扩展管理页。
  2. 开启右上角的“开发者模式”。
  3. 把这个文件夹整个拖到扩展管理页。
  4. 如果拖拽没有反应，点击“加载解压缩的扩展”，选择这个包含 manifest.json 的文件夹。

扩展管理页地址

Chrome chrome://extensions
Edge edge://extensions

复制后粘贴到浏览器地址栏并回车即可打开。

开始下载

  • ✓先在同一个浏览器里登录钉钉网页。
  • ✓确认目标直播回放能正常播放。
  • ✓打开扩展，粘贴回放链接，或在回放页点击“使用当前页”。
  • ✓选择 MP4 或 TS，然后点击“开始下载回放”。
