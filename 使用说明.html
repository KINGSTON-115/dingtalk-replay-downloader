网页视频下载器 v0.4.0

钉钉只是内置适配器之一；同时支持普通媒体、HLS 和 DASH。

本地处理流式写盘非 DRM按需权限

一、安装扩展

  1. 确认当前文件夹中直接包含 manifest.json，不要继续选择它的上级目录。
  2. 打开 chrome://extensions 或 edge://extensions，开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择当前文件夹。浏览器工具栏会出现蓝色下载图标。

如果你下载的是 GitHub 自动生成的 Source code，需要先运行构建；普通用户应下载 Releases 中的 web-video-downloader-v*.zip。

二、最常用流程

  1. 在同一个浏览器中登录目标网站，确认目标视频能正常播放。
  2. 播放视频几秒钟，然后点击扩展图标和“识别当前页”。
  3. 在候选列表中选择 HLS、DASH 或视频文件，点击“解析媒体信息”。
  4. 选择清晰度、音轨、浏览器模式或 FFmpeg 本地增强模式。
  5. 点击“前往任务页下载”。在独立任务页确认保存位置并开始。

下载任务不再运行在容易关闭的弹窗中。弹窗可以关闭，但下载期间请保留独立任务页。

三、识别模式

基础识别

只在你点击按钮时读取当前标签页中的媒体元素、页面元数据和已经加载的资源。它依赖 activeTab 临时权限，不需要默认访问所有网站。

增强识别

点击“增强识别”后，浏览器会询问全站 HTTP/HTTPS 权限。授权后，扩展从页面加载开始记录媒体响应类型、Fetch、XHR 与 MSE 信号，适合没有文件后缀、使用 blob: 播放或很快过期的媒体。

增强识别不会读取 Fetch/XHR 响应正文，也不会复制 SourceBuffer 数据。权限可在浏览器扩展设置中撤销。

五、安装 FFmpeg 本地增强

先安装 Node.js 和 FFmpeg，并在 PowerShell 中确认 node --version、ffmpeg -version 能正常运行。

  1. 在扩展管理页复制本扩展的 32 位 ID。
  2. 打开发布包的 native-host 文件夹。
  3. 运行：
powershell -ExecutionPolicy Bypass -File install.ps1 -ExtensionId 你的扩展ID

默认输出到“下载/网页视频下载器”。卸载命令：

powershell -ExecutionPolicy Bypass -File uninstall.ps1

本地增强和 Cookie 都是单独的可选权限。只有某个媒体在 FFmpeg 中确实提示未授权时，才建议勾选“提供当前媒体域的 Cookie”。

六、常见问题

只看见 blob 地址

点击“增强识别”，刷新页面，再开始播放。扩展要寻找的是 blob 背后的 HLS、DASH 或媒体分片。

解析成功但浏览器模式得到两个文件

网站使用了独立视频轨和音频轨。使用 FFmpeg 本地增强可合并；也可以保留两个轨道文件自行处理。

提示 DRM 或 ContentProtection

这表示媒体由 Widevine、PlayReady、FairPlay、SAMPLE-AES 等机制保护。本扩展不会绕过 DRM。

403、401 或地址过期

确认页面仍能播放，重新识别以获取新地址，并授权实际 CDN 域名。不要在日志或截图中公开带签名的完整 URL。

下载过程中关掉了任务页

浏览器会结束页面内任务。重新打开扩展并开始新任务；普通文件由浏览器下载器接管后不受任务页影响。

七、安全与合规

  • 只下载你有权访问、保存和备份的内容。
  • 扩展不会绕过登录、访问控制、付费限制或 DRM。
  • 任务历史保存的是脱敏地址；媒体候选保存在浏览器 session storage 中。
  • 默认安装没有全站 Cookie 读取能力。
